Examples
========

Each example is a short script focusing on a specific aspect. They follow the
three levels of the library, plus data loading. Every page can be downloaded as a Python
script or a Jupyter notebook.

To run an example, install the ``data`` extra (``pip install -e ".[data]"``). Datasets are
downloaded or generated on first use into ``~/.cache/pyc``, or the folder in ``PYC_CACHE``
(see :doc:`Datasets <guides/using_data>`).
